Selected projects

Work that moves between web delivery and infrastructure thinking.

Each project below is framed as a system, not a screenshot — the question I'm always asking is what survives once real users, traffic, and failure are involved.

Lab · AWS / Terraform

Three-tier VPC with private-by-default routing

Outcome

Public, application, and data tiers fully isolated. Application and data subnets carry no internet route by default; egress flows through a NAT gateway and is captured in VPC Flow Logs for review in Athena.

Proof system

Terraform module with explicit CIDR layout, route tables, security groups, and IAM boundaries. CloudTrail enabled, GuardDuty findings routed to Security Hub. Designed to be torn down and rebuilt cleanly from code.

Lab · Observability stack

End-to-end logging and detection on a hardened VPC

Outcome

A baseline observability layer where every accept and reject in the network is queryable, every API call is recorded, and a malicious pattern surfaces in a dashboard rather than a postmortem.

Proof system

VPC Flow Logs to S3, queried with Athena. CloudTrail organization trail with KMS-encrypted log storage. CloudWatch alarms on root-account use and IAM changes. GuardDuty findings centralized through Security Hub.

Applied · Agency × Cloud

Hardening agency client sites with AWS edge services

Outcome

A repeatable pattern for putting CloudFront, WAF, and Route 53 in front of CMS-driven client sites — moving security and TLS termination to the edge instead of leaving it on a single origin server.

Proof system

Three years of production agency work on Mercedes-Benz, Cadillac, and Northwell Health sites informed the constraints. Lab environments translate that hosting experience into AWS-native architecture: edge caching, managed certs, DNSSEC, KMS-encrypted asset storage.

Discipline

How I think about the work — and why I chose this layer of the stack.

Most modern applications depend on infrastructure that is reliable and secure. I want to work at the level where performance, security, and system design come together.
Personal thesis
01

Private by default

The default state of any resource I provision is no public exposure. Access is opened deliberately, narrowly, and with a logged reason — never as a side effect.

02

Observable end to end

If I cannot prove what a system did, I cannot defend it. Logs, metrics, and audit trails are part of the build, not added when something breaks.

03

Resilient under pressure

Reliability shows up in the boring states: failover, retries, the calm rebuild from code. The interesting design happens before the incident, not after.
